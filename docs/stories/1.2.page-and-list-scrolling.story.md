## Story

**As a** Zig UI developer,
**I want** to make any container element scrollable when its content overflows,
**so that** I can build pages with long content and scrollable lists without content being clipped or invisible.

## Acceptance Criteria

1. An element can be marked as scrollable via an `overflow` style property (e.g., `overflow: .scroll`)
2. Vertical scroll works with mouse wheel input on Linux (Wayland), macOS, and Windows
3. Scroll animation uses the existing spring physics (`useSpringTransition`) for smooth deceleration
4. Content that overflows the container bounds is not rendered (correct Vulkan scissor clipping)
5. A working scroll demo exists in `playground.zig` showing content taller than 2× the window height
6. `zig build test` and `zig build run` (playground) pass without errors

- Scroll horizontal (defer — não necessário para MVP)

## Dev Notes

**Architecture Decision (from `docs/architecture.md`):**

This story uses the **4-layer scroll architecture**:

```
Layer 1: Style    → overflow: Overflow enum in node.zig
Layer 2: Layout   → clipRect: ?Rect in LayoutBox (layouting.zig)
Layer 3: Render   → vkCmdSetScissor scissor stack in graphics.zig
Layer 4: Input    → useScroll() hook + mouse wheel routing in root.zig
```

**Reusing existing infrastructure:**
- `useSpringTransition(target, config)` already implemented in `src/root.zig` (line ~451)
- `SpringConfig = struct { stiffness, damping, mass }` already defined
- `hoveredElementKeys: std.ArrayList(u64)` in Context — use for scroll hit-testing
- Scroll event routing: find outermost (or innermost?) scrollable element in `hoveredElementKeys`
- **Decision from architecture doc:** innermost element in hover stack receives scroll event

**Vulkan Scissor Notes:**
- `vkCmdSetScissor` requires integer pixel coordinates (VkRect2D with offset + extent)
- Convert `Rect` (f32) to `VkRect2D` (i32) at render time
- Initial scissor state = full viewport (no clipping) when scissorDepth == 0
- CRITICAL: Scissor state must be restored after each scrollable container renders

### Completion Notes List
